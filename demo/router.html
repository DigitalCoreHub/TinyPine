About TinyPine

TinyPine is a minimal reactive micro-framework that makes building interactive web applications simple and fun.

Version 1.5.0 introduces a complete routing system with:

Smart Router Engine

Hash-based routing with dynamic parameter extraction and pattern matching.

🔒 Access Granted

Welcome to the admin panel! This route should be protected by guards in production.

In production, you would add a beforeEnter guard to verify authentication: 

TinyPine.router({
    routes: {
        'admin': {
            beforeEnter(to, from) {
                const isLoggedIn = TinyPine.store('auth').loggedIn;
                return isLoggedIn ? true : '/login';
            }
        }
    }
});
