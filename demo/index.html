Simple.

Declarative syntax that feels natural. Just add attributes to your HTML.

Lightweight.

Only 30KB minified. No build step required. Drop it in and go.

Powerful as hell.

Everything you need: reactivity, routing, i18n, stores, and more.

There is no better way to get a feel for what TinyPine is and what it can do, than by seeing it for yourself:

t-data

Declare a new component and its data
<div t-data="{ count: 0 }">
  <button t-click="count++">+</button>
  <span t-text="count"></span>
</div>

t-text

Set the text content of an element
<div>
  Copyright ©
  <span t-text="new Date().getFullYear()"></span>
</div>
Copyright ©

t-show

Toggle the visibility of an element
<div t-data="{ open: false }">
  <button t-click="open = !open">Toggle</button>
  <span t-show="open">Content...</span>
</div>
Content appears when open is true!

t-click

Listen for click events
<button t-click="count++">+</button>

t-model

Synchronize data with input elements
<div t-data="{ search: '' }">
  <input type="text" t-model="search">
  Searching for: <span t-text="search"></span>
</div>

Searching for:

t-for

Repeat a block of HTML based on a data set
<div t-data="{ items: ['One', 'Two', 'Three'] }">
  <div t-for="item in items">
    <h2 t-text="item"></h2>
  </div>
</div>

t-init

Run code when an element is initialized
<div t-data="{ date: new Date() }">
  <span t-text="date.toLocaleString()"></span>
</div>

t-ref

Reference elements using $refs
<input type="text" t-ref="input">
<button t-click="$refs.input.focus()">Focus</button>

$store

Access global stores registered with TinyPine.store()
<h1 t-text="$store.site.title"></h1>

$el

Reference the current DOM element
<div t-init="$el.style.background = 'purple'">...</div>
This div's background was set via $el
