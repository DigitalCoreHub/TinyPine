📚 API Reference

Core Directives

  • t-data - Define reactive state
  • t-text - Update text content
  • t-show - Toggle visibility
  • t-bind - Bind attributes
  • t-class - Dynamic classes
  • t-model - Two-way binding
  • t-click - Click handlers

Advanced Directives

  • t-for - List rendering
  • t-ref - DOM references

Context Accessors

  • $parent - Access parent scope
  • $root - Access root scope
  • $refs - Access DOM references
  • $el - Current element

Event Modifiers

  • .prevent - preventDefault()
  • .stop - stopPropagation()
  • .once - Execute once
  • .outside - Detect outside clicks

🧩 Plugin System

Custom plugins can extend TinyPine with new directives and functionality 

TinyPine.use({
  name: 'LoggerPlugin',
  init(TinyPine) {
    TinyPine.directive('log', (el, value) => {
      console.log('[t-log]', value);
    });
  }
});
