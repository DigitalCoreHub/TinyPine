# TinyPine.js v0.4.0 - Global Store, Watchers & SSR

## 📋 Implementation Plan

### Phase 1: Global Store System (1-2 hours)
**File:** `src/store.js`

**Features:**
- `TinyPine.store(name, data)` - Create global reactive store
- `$store` access in all `t-data` scopes
- Proxy-based reactivity for global state
- Automatic propagation to all components

**Implementation:**
```javascript
// store.js
const globalStores = new Map();

TinyPine.store = function(name, data) {
  // Create reactive store
  const reactiveData = reactive(data, (key, value) => {
    // Update all components using this store
    updateAllComponents();
  });

  globalStores.set(name, reactiveData);
  return reactiveData;
};

// Inject $store into context
const proxiedData = new Proxy(state, {
  get(target, prop) {
    if (prop === '$store') return globalStores;
    return target[prop];
  }
});
```

### Phase 2: Watchers (1 hour)
**File:** `src/watch.js`

**Features:**
- `TinyPine.watch(path, callback)` - Watch reactive changes
- Support global and local paths
- Deep watching with dot notation

**Implementation:**
```javascript
// watch.js
const watchers = [];

TinyPine.watch = function(path, callback) {
  watchers.push({ path, callback });
};

// Trigger watchers on state change
function triggerWatchers(target, key, newVal, oldVal) {
  watchers.forEach(({ path, callback }) => {
    if (path === `${target}.${key}`) {
      callback(newVal, oldVal);
    }
  });
}
```

### Phase 3: SSR Hydration (30 minutes)
**File:** `src/ssr.js`

**Features:**
- Auto-detect `window.__TINYPINE_STATE__`
- Initialize global stores from server state
- Merge with existing stores

**Implementation:**
```javascript
// ssr.js
if (window.__TINYPINE_STATE__) {
  Object.keys(window.__TINYPINE_STATE__).forEach(name => {
    TinyPine.store(name, window.__TINYPINE_STATE__[name]);
  });
}
```

### Phase 4: A11Y Support (1 hour)
**File:** `src/a11y.js`

**Features:**
- Auto-add `aria-hidden` to `t-show` elements
- Auto-add `aria-expanded` to collapsible elements
- Auto-add `aria-label` to buttons with t-click
- Ensure `t-for` lists have proper roles

**Implementation:**
```javascript
// a11y.js
function enhanceAccessibility(element, directive, value, state) {
  if (directive === 't-show') {
    element.setAttribute('aria-hidden', !evaluateExpression(value, state));
  }

  if (directive === 't-click') {
    if (element.tagName === 'BUTTON' && !element.getAttribute('aria-label')) {
      element.setAttribute('aria-label', value);
    }
  }

  if (directive === 't-for') {
    element.setAttribute('role', 'list');
    element.setAttribute('aria-live', 'polite');
  }
}
```
