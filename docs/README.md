## 🆘 Getting Help

1. **Check console first** - Most errors show detailed messages
2. **Enable debug mode** - `TinyPine.debug = true`
3. **Read relevant guide** - See index above
4. **Search GitHub issues** - Someone may have encountered the same problem
5. **Ask in Discussions** - Community support
